## What you get

- One-command local stack (`docker compose up`)
- Web UI, CLI, and MCP for Cursor and other local agents
- Multipage PDF pipeline (diagnose → plan → page digests → stitch)
- Self-hosted Trigger.dev + Langfuse
- Truth-fixture evaluation under `data/datasets`
