## Dataset-first by design

Datasets are the primary managed assets. Annotations, quality reports, transformations, experiments and models connect to exact dataset versions.

The accepted target combines React/Vite, FastAPI/FastMCP, Pydantic v2 and PostgreSQL with Prefect, DataChain, Label Studio, MLflow, Evidently, S3-compatible storage and OpenTelemetry with Grafana OSS, Mimir, Loki and Tempo.

**Readiness:** this site describes the target architecture. The documentation refactor does not implement or deploy it; existing source may still run the earlier digestion tool.
